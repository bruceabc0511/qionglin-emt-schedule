# 芎林義消救護分隊｜協勤線上排班系統

救護義消用來登記每日協勤班次的網頁。資料存放在 Google 試算表，並自動產生與原本 EXCEL 相同格式的月排班表。

## 專案結構

```
├─ index.html              前端主頁面
├─ css/style.css           樣式表（主色調 #66B3FF）
├─ js/
│  ├─ config.js            ★ 系統設定（API_URL、班別規則、每月20號開放設定、達標門檻）
│  ├─ api.js               API 介面（Google 試算表連線／離線模式）
│  └─ app.js               前端主程式
└─ apps-script/            Google Apps Script 後端（貼到 Google 試算表）
   ├─ Code.gs
   └─ appsscript.json
```

## 排班規則

| 項目 | 規則 |
|---|---|
| 一車（綠色） | 08:00～22:00，每班 4 小時，**每 1 小時為一區間**（08-09、09-10…，可選 08:00、09:00、10:00…18:00 起算），每天原則上 3 班 |
| 二車（黃色） | 08:00～18:00，每班 4 小時，**每 1 小時為一區間**（可選 08:00～14:00 起算），每天最多 2 班；管理員可依每日狀況**開放或鎖定**二車時段 |
| 次月班表自動開放 | **每月 20 號 00:00 自動開放選填次月班表**（20 號前僅供預覽，管理員可先行排班；Apps Script 亦會在每月 20 號自動建立次月工作表） |
| 排班率與達標 | 一車已排班數 ÷（當月天數 × 3），二車**不列入**。每月協勤率達 **90% 以上**顯示「✓ 已達標」 |
| 定期訓練日 | 每月**第一個星期三**於日期後方自動顯示 `(定訓)`（網頁與 Google 試算表同步顯示） |
| 先送出者先得 | 伺服器用 `LockService` 鎖定後再讀取最新資料並檢查衝突，同一時段後送出的人會被拒絕，並收到「已被○○搶先登記」的提示 |
| 本人／管理員異動 | 一般成員僅能修改或取消自己的班；**管理員**可代為新增、修改或取消他人的排班，系統會自動標註 `(管理員異動)` |
| 同人同時段 | 同一人不能在同一時間同時登記一車與二車 |
| 過去日期 | 一般成員不能新增或修改過去日期（管理員不受限） |

## 連接 Google 試算表

1. 建立一份新的 Google 試算表，例如命名為「芎林義消協勤排班」。
2. 選單 **擴充功能 → Apps Script**。
3. 把 `apps-script/Code.gs` 的內容貼進 `程式碼.gs`。
4. 開啟 **專案設定 → 勾選「在編輯器中顯示 appsscript.json」**，再把 `apps-script/appsscript.json` 的內容貼上。
5. 在編輯器上方選擇函式 `setup` → **執行**，並依提示授權。執行後會：
   - 建立「人員清單」和「排班紀錄」工作表
   - 匯入 24 位人員（預設 PIN `0000`，首次登入時需變更）與管理員帳號 `管理員`（PIN `9999`）
   - 產生本月排班表工作表，並設定每日觸發器於每月 20 號自動建立次月排班表
6. **部署 → 新增部署作業 → 類型：網頁應用程式**（執行身分：**我**；存取權：**所有人**）。
7. 複製網頁應用程式的網址（結尾是 `/exec`），貼到 `js/config.js` 的 `API_URL`。

## 管理員專屬功能
用管理員帳號（預設 `管理員` / PIN `9999`）登入後：
- **代為修改／新增他人排班**：點選月曆上任何人的班次或空白時段，可在對話框選擇人員並修改時段，班次卡片與 Google 試算表皆會自動標註 `(管理員異動)`。
- **開啟／鎖定二車時段**：
  - 可直接點擊月曆每日右上角的 `🔓二車` / `🔒二車` 快速切換該日二車是否開放。
  - 或點選頁首「🚑 二車時段管理」批次管理整月各日的二車開放狀態。
- **人員管理**：點選頁首「👥 人員管理」可新增人員、刪除（停用）人員、恢復人員或重設 PIN。
